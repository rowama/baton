# Lay out the project

Using the owner's description, the site survey and the site photo, write a layout plan
(`layout_plan`, Markdown) a person can build from: a footprint with dimensions, where it
sits relative to fixed features, and the decisions that shaped it.

Return a one-paragraph `summary`, the `footprint` in metres, and each decision as a line
in `decisions`. Respect every hazard the survey lists; if one makes the project unsafe as
described, set `status` to `blocked` and ask the owner.
