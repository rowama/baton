# Assess the project's size

Rate this backyard project on the recipe's scale, using the `criteria` input exactly.

The project, in the owner's words, is in the `description` input. When the project is
being adopted from work already under way, the `research` input lists what already exists.

Return `level` (one of `minor`, `standard`, `major`) and `reasons`: one short line per
criterion that decided it, naming the criterion. Do not plan the work; only size it.
