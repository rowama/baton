# Process plan: Start a business selling purified water from a few self-serve machines around town.

The parts of this goal, what choosing each one starts, and where each stands. Nothing here is scheduled: a part starts only when you choose it.

## Setting up the business

Registering it, banking, insurance and permits.

- **Status:** started (fit-check, run <run1>)
- **Ref:** `<run0>/setup`

## Building the first machine site

Preparing the ground and shelter for the first machine.

- **Status:** started (backyard-project, run <run2>)
- **Ref:** `<run0>/kiosk`

## Signs for the sites

Signs that tell passers-by what the machine is.

- **Status:** started (backyard-project, run <run3>)
- **Ref:** `<run0>/signage`

## Running the machines day to day

Refilling, cleaning and collecting payments.

- **Status:** for later
- **Choosing it starts:** a fit check: a few questions and a recommendation, no commitment
- **Ref:** `<run0>/running`
