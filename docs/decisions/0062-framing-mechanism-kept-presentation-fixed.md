# 0062. Framing's select keeps its mechanism; only its presentation is fixed

## Context

Framing asks the owner which parts of their goal to start on. From the process side that is right: choosing a part starts what that part proposes, which is usually a quick fit check (a few questions and a recommendation, no commitment), or a fitting recipe. The owner thinks about the goal, not the process, and read "which parts should we start work on now" as "start marketing now". The `frame.select` label made it worse: its effect said "Work starts now on the parts you chose", which overstates what happens.

## Decision

Keep the mechanism: `select` starts what each chosen part proposes (§11.6). Fix how it is presented: each decision option carries what choosing it triggers, in process-neutral words computed from the record, the label and effect say accurately what happens, and the Director translates the question into the owner's world before asking it.
