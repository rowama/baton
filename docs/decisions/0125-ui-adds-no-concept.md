# 0125. The setup page adds no concept; it is an interface like the CLI

## Context

Open question 7: whether the page counts against the concept budget (§2, §0 rule 8).

## Decision

It does not. It shows and edits resources, profiles and preferences, which already exist. §2 records it in its interfaces note next to the other no-new-concept entries.
