# 0139. The eng-process recipe blocks on plan review and keeps code review advisory

## Context

The source working-agreement summary calls cross-model review advisory, while its detailed plan skill and PROCESS section 10 explicitly require clean plan review before medium/large implementation. The proposed recipe needs a clear review policy without binding it to a vendor.

## Decision

Plan review is blocking for medium/large work; code review is advisory, following the source's detailed skills. Vendors are chosen through worker profiles. The precise independence level and conditional review rules still need Design. This decision does not approve all remaining process choices or authorize implementation.
