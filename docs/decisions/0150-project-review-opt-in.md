# 0150. Project guidance is an opt-in review process run in short, repeatable runs

## Context

A project holds many processes. An owner with a project-management background wants help choosing which to run next, without Baton becoming a scheduler (§1.3) and without one run lasting the life of the project. Decision 0069 keeps framing's process plan a list that never orders or schedules. The exploration is `docs/catchall/project-process-linkage.md` (§5 D).

## Decision

1. Project guidance is a process the owner chooses to run, never built in by default. Each project review is a short run that reads the project's state and recommends; the owner decides, and nothing starts automatically.
2. When framing identifies several parts, the Director offers this process.
3. Decision 0069 stands by default. Only inside a project review the owner chose may recommendations suggest an order, with reasons.
4. How the review is built (where its selection mechanism lives, what it reads, what it produces) is for `2026-11-project-review`.
