# 0101. When a new idea nearly fits an owner's recipe, the builder offers a widened new version first

## Context

Generality should grow from real jobs, not from a guess on day one. This overlaps the held recipe tree (hold decision 2026-11-08), which must be settled together with it before the tree is un-held.

## Decision

Framing or the builder offers a widened new version of the owner's recipe before proposing a new one. The scope block tells "nearly fits" from "fits". The widened version is a new version (0097).
