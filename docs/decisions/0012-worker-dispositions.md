# 0012. Worker dispositions are provisional until an independent review confirms them

## Context

Who may set `fixed` and `rejected`: the next iteration's worker with evidence, or only the Director?

Suggested: worker with evidence.

## Decision

worker with evidence, strengthened: a worker's `fixed`/`rejected` is provisional until an independent review confirms it (a re-reported finding id reopens it); with no later review it does not close the finding; persistent worker–reviewer disagreement goes to the owner (§9.2).
