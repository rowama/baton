# 0044. Framing existing projects is deferred

## Context

Phase 17 built framing for new work. An owner adopting Baton into a mature project would benefit from the same guided start.

## Decision

Deferred from Phase 17. Framing that takes the `detect` result into account and can propose bringing existing work under a recipe (an adoption, §11.1) as well as new work was planned as Phase 18, with its acceptance criteria to be defined with the owner before work starts. It is now future work for a change doc (`docs/changes/`).
