# 0065. Owner notes: recorded verbatim, only when asked, in an opt-in notes file; never fed into a step

## Context

When the owner asks the Director to remember a thought, Baton had nowhere to put it.

## Decision

Notes stay informal and under-processed.

- Notes are taken only when the owner asks the Director to remember or note something.
- The Director mentions briefly that the owner can keep notes anywhere they like, and offers once to keep a simple notes file for this project. A note is recorded only in that file, once the owner has accepted it.
- No note is fed automatically into any step, run or backlog deliverable. Notes are not a process input.
- Recording is verbatim and deterministic. Recalling or organizing notes goes to the project SME with the notes file as a reference. No new SME subject.

**Revised the same day, before design** (owner, 2026-11-05): an earlier wording sent a note to an active run's backlog deliverable when its recipe declared one. The owner removed that, because it formalized notes too broadly.

**Later, out of scope here:** a separate, out-of-band interaction may offer the owner the option to incorporate a note more formally. The note then moves to the appropriate process-formal place (for example a run's inputs or a recipe's backlog deliverable) through that place's own mechanism. Not designed yet.
