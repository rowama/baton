# 0004. The runtime maintainer owns the capability vocabulary and classification rules

## Context

Who maintains the capability vocabulary and classification rules, and how changes are proposed.

## Decision

the runtime maintainer; changes are proposed as a PR to the runtime repo that adds a new version file (published versions are never edited).
